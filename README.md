### 候选改动：被移除的功能按钮正确结束拖动（未发布）

- 用实际 Main.qml 的离屏右键拖动复现：拖动中的可选按钮被取消固定后，旧按钮销毁，却没有释放自己的交互状态。松开鼠标后，聊天逐字显示和资源清理仍处于暂停状态；没有原生控制器或控制器拒绝接管时，本地交互计数也会残留。干净基线 `artifacts/local-gesture-teardown-red.json` 共 9 个场景，其中 3 个移除场景失败、6 个正常释放/同内容刷新场景通过，零 QML 警告。

- 最终 21 种离屏组合全部通过，覆盖控制器缺席、拒绝、接受，以及松手、刷新、移除、重排、重叠操作、隐藏和重新添加。重叠时本地交互数按 `2 → 1 → 0` 结束，不误清另一项操作。两组相关回归共 132 项通过，无失败或跳过；组合测试包含在其中，没有重复计数。

### 候选改动：合并交错窗口事件，保留重要状态切换（未发布）

- 实测先区分了“工具自身查元数据”和“窗口是否回复消息”。对当前安装版 v0.3.56 的 20 次只读响应查询全部收到回复，消息调用为 0.1251–1.4608ms；窗口枚举为 3.7753–15.4387ms。使用的是不执行操作的 [Windows WM_NULL](https://learn.microsoft.com/en-us/windows/win32/winmsg/wm-null)，它只验证消息响应，不代表真实鼠标队列、人物拖动、GPU 呈现或模型并行体验。没有截屏、读取标题/聊天或操作窗口。
- 源码压力测试随后复现了另一个问题：两个窗口的 10,000 条位置事件交错出现时，相邻合并失效，队列积压到 2,048 条并丢掉之前的前台切换。更多不同窗口的位置事件也会挤掉前台和销毁事件。失败证据保存在 `artifacts/win-event-backpressure-before.xml`；这并不是在用户桌面重放过的工作负载，不能据此认定日常卡顿已被解释。
- 队列现在在没有状态边界的一段事件中，按窗口身份保留最新位置通知；新通知保持最新发生顺序。前台、显示/隐藏、最小化、移动起止与销毁均作为边界，不跨边界合并，也不把不同原生线程的同值句柄当作同一窗口。
- 达到上限时先丢弃旧位置通知，不让它挤掉重要状态事件；所有事件均为重要状态且仍超限时，仍采用有界的最旧丢弃规则，不声称可以无限保存。回调继续只在调用 `dispatch_pending` 的线程执行，原生收集线程不运行界面逻辑，不增加线程或轮询频率。
- 相同的两窗口压力场景现在只交付 3 条事件（前台切换和各窗口最后一次位置）；另用真实 Backend 加假窗口信息验证了位置洪峰之后仍进入隐私保护状态。混合事件/部分读取、重入、并发生产和索引边界另有回归覆盖。这里减少的是重复工作，不是已经测得真实拖动速度提高多少倍。
- 原始响应与元数据结果位于 `artifacts/window-response-installed-20261005-a.json`、`artifacts/installed-metadata-costs-20261005.json`。查询程序只发送固定空消息，持有并核对进程路径、创建时间和窗口所属线程，拒绝广播，单次消息等待上限 75ms；同步元数据查询本身并不因此获得硬超时保证。
- 259 项窗口/栖息/隐私/后台与 QML 回归，以及 86 项事件与测量边界检查通过；两组有 21 项重叠，去重后 324 项，无失败或跳过。新候选 `v0357-event-queue-20261005-a12` 的离屏自检、资源、点击区域和隐藏 Windows 启动检查通过，零 QML 警告；2472 个文件及源码再次核对一致。旧 a11 正确被拒绝为过时，仍保留供追溯。
- 当前运行版没有被替换、重启或终止；候选发布门禁继续关闭。真实拖动、切换应用时的延迟、模型并行、原生画面和长期使用仍须验收。

### 候选改动：诊断数据不再默认落到系统临时目录（未发布）

- 未指定 `LILIES_DATA_DIR`，或只包含空白时，诊断启动会在固定 F 盘数据根的 `diagnostics` 下创建一次性的随机子目录，不使用系统 `TEMP` 或安装目录。F 盘不可用、父目录被重定向或分配失败时，直接返回失败，不恢复真实桌面、不弹出窗口。
- 显式诊断目录也必须在同一专用磁盘，不能是正式用户数据根、其上级或指向它们的链接。普通启动、显式测试与截图助手的权限边界没有放宽。直接创建诊断 Backend 而没有隔离目录现在会拒绝，避免误开正式数据库。
- 自动目录在正常返回、非零返回和异常路径均收尾，并恢复调用前的环境变量；调用者指定的目录不会被清理。只移除了本次自建的测试数据，未读取或删除用户聊天、凭据、数据库或恢复备份。
- `diagnostic-data-before.xml` 保留了 13 项修复前失败。最终 225 项路径/恢复/启动检查与 91 项聊天/业务/迁移回归通过，合计 316 项不同测试，无失败或跳过。实际源码启动另测了“未设目录”的离屏自检与隐藏 Windows 自检：使用 F 盘合成数据根，退出后临时数据库和 Qt 缓存已清理，系统临时目录哨兵保持为空，隐藏检查中没有可见窗口或托盘。
- 新独立候选 `v0357-diagnostic-data-20261005-a11` 的打包、自检、资源、点击区域与隐藏 Windows 启动检查通过。2472 个文件与源码再次核对一致，旧 a10 已被正确拒绝为过时；测试结果不等于完整发布验收。
- 另保存了当前安装版 v0.3.56 的约 38 秒只读进程采样：未请求模型、截屏、操纵窗口或注入输入。采样期间进程响应，线程数稳定，但测量与其他隐藏诊断并行，采样间隔也有波动，不能据此判断拖动延迟或长期稳定性。原始计数在 `artifacts/installed-process-passive-20261005.json`。

## v0.3「共鸣」

- 分层二头身桌宠会呼吸、栖息在稳定窗口边缘，并在敏感窗口、会议、远程桌面和全屏游戏中自动静默或隐藏。

- 本地任务、专注、论文阅读和提醒即使模型离线也能运行；专注切到娱乐应用 45 秒后只提醒一次。
- 共鸣值由不可变事件账本计算，任务、专注、阅读、Slack 整理与主动休息会确定性解锁服装、姿态和盒中陈设，失败与延期不扣分。
- Google Calendar 与 Slack 默认关闭。连接后默认采用“必要范围 + 安静 + 元数据 + 协助”；OAuth 使用系统浏览器，令牌只进入 Windows Credential Manager。
- Calendar 修改和 Slack 回复只生成不可变预览，必须在连接器窗口逐次确认后才提交；模型没有直接提交、授权、Token、任意 Shell 或成长授予接口。
- 专注开始后，莉莉丝旁会出现不抢焦点、可穿透点击的呼吸计时环；自然到时、手动结束、取消、暂停和全屏静默使用不同状态，顶部空间不足时计时环自动移到人物侧边。
- 桌宠会按小窗、中窗、大窗、窄标题栏、顶部空间不足和最大化窗口选择坐姿、趴伏、倾听或侧边探身；按 DPI 与真实标题栏高度贴合，并用滞回与锚点插值避免窗口临界尺寸反复跳姿态。
- “莉莉丝桌面／仅桌宠”与“看桌面／返回工作”已明确分开；前者切换外壳，后者只临时收起并恢复本轮窗口。

## v0.2 延续能力（v0.3 继续保留）

- 看桌面：按 `Ctrl+Alt+D` 或点击桌宠旋出菜单中的“看桌面”，第一次只临时最小化当前虚拟桌面上原本未最小化的应用，第二次恢复本次由 Lilies 收起且身份仍匹配的窗口和前台焦点。当前原生/Lilies 桌面模式不会切换，快捷键可在设置中修改；崩溃恢复日志位于 F 盘。
- 主动陪伴：内容可选科普、吐槽、笑话、新闻、科研进展与盒中世界；支持关闭、安静、平衡、活泼和自定义频率，兴趣/场景比例、场景半衰期和各类别权重均可调。气泡不抢焦点，可展开、回复、换一个、暂停、对当前应用静默或转入盒子。
- 智能观察：默认关闭。明确开启后，仅在窗口稳定、用户自然停顿且冷却满足时截取一次当前活动窗口；密码、支付、会议、远程桌面、隐私浏览、UAC、受保护内容与全屏游戏默认拒绝。暂存图片在请求完成、失败或取消后删除，只有“保存此刻”才写入图库。
- 实时内容：默认关闭。明确开启后可更新 arXiv、Crossref、PubMed、RSS、NASA/JPL 与可选 GDELT 元数据，只缓存标题、来源、日期、链接和短摘要。新闻与科研气泡必须显示来源和日期，离线或过旧内容不会宣称“最新”。
- 分区记忆：原始对话立即进入 F 盘“待归档”，后台空闲时由 Luna 整理进身份、关系、偏好、项目、研究、日常、世界观等固定分区。模型只能通过只读 `memory.recall` 按需取回最多 6 段；身份与称呼核心事实固定注入。记忆地图可以查看出处和查阅原因、改分区、忘记或经二次确认删除原对话。
- 私有数据：Lilies 创建的数据库、聊天、缓存、截图暂存和运行状态固定在 `F:\code\Lilies in the box\private-data`。F 盘不可用时只执行受限恢复，绝不静默回退写入 C 盘。旧数据经 SQLite Backup API、完整性校验、F 盘备份和两次启动验证后才清理。
- 输入脉冲：只在内存中保留最近 3–10 秒的活跃率、停顿、节奏和量化鼠标方向，不保存字符、按键或窗口标题；允许状态下的光标位置读取最高 30Hz，也不进入数据库、日志或模型上下文。

- 桌面图标：拖动可改位置；右键可以固定、隐藏、分组或打开所在位置。设置页可以复制、切换和删除多套虚拟布局，真实文件不会被移动。
- 桌宠：莉莉丝正面、二头身、抱拳并微微颔首。她使用独立窗口，切换完整桌面时不会被替换或隐藏。默认“始终置顶”，人物、盒子和功能环都可以点击，周围透明区域则穿透到 WPS 或游戏；设置中可切换为“普通窗口”，保留交互但允许其他应用遮挡她。单击人物后，对话、盒中世界、设置 3 个常驻入口与最多 3 个自选入口围绕她旋转展开；选择功能后自动收环。拖动超过 4px 时立即进入精确跟随并收环，不再二次采样光标造成首帧跳动；在人物上滚轮或脚边 `↘` 手柄可调整整体大小。圆形“盒子”可独立拖动、滚轮缩放，红绳端点实时绑定盒缘。
- 功能按钮：设置页的功能库决定 3 个自选槽位；展开后可用右键拖动单个按钮，用滚轮缩放。人物、盒子和按钮的位置会跨重启保存。
- Dock：完整桌面底部默认只保留一枚居中的 64×6 暖白纸边与暗红绳结；悬停后展开为 52px 高的浅纸折边。运行窗口按应用身份分组，最多显示 7 个应用组，同组窗口以数量角标和最多 6 个 MRU 预览呈现；更多窗口进入单层、可搜索、虚拟化滚动的“全部窗口”抽屉。50 窗口场景不会一次创建全部窗口卡片，少量窗口时抽屉会按内容收高，移开后自动折回纸边。
- 对话：GPT Terra 通过当前 ChatGPT/Codex 订阅模拟莉莉丝，回答流式出现；Enter 直接发送，Shift+Enter 换行。支持本地历史搜索、新对话、重试和停止生成。模型先看到分区目录，仅在需要时调用只读记忆检索；明确问“你还记得……”会强制检索一次。
- 应用启动：可以直接对莉莉丝说“打开 WPS”“我要打开 WPS”或“帮我启动一下 WPS”。应用只从桌面和开始菜单的受控索引中选择；索引过期时会自动刷新，遇到多个不同结果会先要求完整名称，不会把对话内容当作任意系统命令执行。
- 文件与网页：可以说“打开下载文件夹”“打开论文.pdf”“打开 F:\\资料\\报告.docx”“打开 GitHub”“访问 example.com”或“上网搜索 莉莉丝”。按名称查找只覆盖桌面、文档、下载和手动添加目录，完整路径可以指向其他现有位置；网页只允许 HTTP/HTTPS。
- 论文卡片：术语卡生成成功后自动保存；简释、翻译和追问只有点“收进盒”才会落入本地 SQLite。盒子的“阅读”页可以搜索原文、回答、标题和问题并按类型筛选。保存的卡片会进入本地研究记忆索引，可被后续记忆检索召回；不会自动拼入每次划词请求。可在记忆页要求忘记，或删除阅读卡及其对应索引。
- 命令边界：v0.3 不注册终端组件，也不接受自然语言或固定前缀执行 Shell；应用、文档、文件夹与网页仅通过各自受限组件打开。
- 身份保护：身份与称呼核心事实固定注入。订阅模型自行回答问候，不再被固定台词替代；本机 0.5B 保留程序层身份保护。历史中的旧身份错误不会继续注入模型，称呼串位也会被清洗。
- 权限：标准模式允许读取与启动；修改操作需要确认。信任模式可逐项设置写操作白名单，破坏性动作仍需确认。
- 登录外壳：只有视觉模式健康检查通过后才允许手动启用，并在下一次登录生效；Explorer 同时保留为启动失败回退。
- 性能：实时场景和电影循环都会报告真实 FPS；完整桌面被最大化窗口完全遮挡时暂停动画/视频。0.5B 工作进程使用后台优先级，避免抢占桌面渲染。

姿态、服装、UI 方向稿与后续高价值功能顺序记录在 [docs/v0.2-evolution.md](docs/v0.2-evolution.md)。

## 安全说明

- 默认视觉外壳只隐藏 Explorer 桌面图标和任务栏，不结束 Explorer。
- 独立 watchdog 会在主程序异常退出后恢复 Windows 桌面。
- 实验性登录外壳不会自动启用，必须在设置中明确确认。
- “退出并恢复 Windows”会先恢复任务栏和桌面，再结束程序。
- 智能截图和联网内容源均默认关闭，必须分别在“陪伴”页明确开启。
- 所有屏幕文本、历史对话与网页摘要都按不可信数据处理，不能扩大组件权限或触发终端。

## 开发运行

```powershell
cd "F:\code\Lilies in the box"
.\scripts\setup_windows.ps1
.\scripts\run_windows.ps1
```

需要重新生成个人版程序时：

```powershell
.\scripts\build_windows.ps1 -OffscreenOnly
```

此命令只创建隔离候选包。默认生成唯一构建编号；也可通过 `-BuildId v0357-自己的编号` 指定，已经使用的编号会被拒绝。结果位于 `dist\<构建编号>\LiliesInTheBox`，报告位于 `artifacts\<构建编号>`，旧构建不会被删除或覆盖。

每次按顺序生成来源清单、实际包完整性、打包程序自检、紧凑资源和姿态点击报告，任一步失败即停止；只有全部通过才写入 `candidate-build.json`。离屏模式没有 `packaged-windows-startup-v0357.json`，回执会明确记为 `not-run`，不会冒充原生验证。人工排查必须向检查脚本显式传入本次可执行文件、资源目录及报告路径，不能使用指向旧 `dist\LiliesInTheBox` 的默认值。

暂勿运行候选树的安装脚本或旧的 `promote_v0356.ps1`。新版本的迁移、回滚与发布流程尚未完成，包内一致性和离屏通过都不等于可以替换当前安装。

## Calendar / Slack 初次连接

- Calendar：在 Google Cloud 创建个人 Desktop OAuth Client，只把 Client ID 填入连接向导，再由系统浏览器授权。默认只读；将协助档位手动升级为“确认执行”后，才会重新申请 owned-events 写权限。
- Slack：先由设置页生成 manifest，在 Slack 创建个人 custom app，启用 Socket Mode，并创建只含 `connections:write` 的 xapp token；再填写 Client ID、`127.0.0.1` 回调地址、本人 Slack User ID、xapp token 与可选频道 ID 后授权。
- 两个连接器都不使用 OpenAI API Key，但需要你自己的 Google/Slack OAuth 应用；组织管理员可能拒绝 Slack 权限。
- 默认“元数据 + 协助”只表示协助能力可用，元数据档并不保留正文，所以无法总结或拟稿。先把留存升为“可搜索摘要”或“扩展缓存”，再明确点选一项；每次只把该项与本次指令交给 Luna，不附带相邻项目、长期记忆或组件权限。

## 安装与卸载

以下安装命令保留作为已发布版本的说明，**不适用于当前隔离的 v0.3.57 候选包**。当前构建不会自动安装；不要把候选目录手工复制到旧的安装输入位置来跳过验收。

安装到当前用户的 `%LOCALAPPDATA%\Programs\Lilies in the box`：

```powershell
.\scripts\install_windows.ps1 -StartAtLogin
```

安装脚本默认启动上次由你选择的桌面/桌宠模式，不再强制紧凑模式。开始菜单同时提供普通入口、明确展开完整桌面的 `Desktop` 入口和 `Pet only` 入口；三者都先激活正在运行的单实例。若不希望安装后立即启动，使用：

```powershell
.\scripts\install_windows.ps1 -StartAtLogin -NoLaunch
```

卸载程序并恢复 Windows；默认保留本地聊天与记忆：

```powershell
.\scripts\uninstall_windows.ps1
```

只有明确需要清除 F 盘私有数据和仍残留的 v0.1 迁移副本时才使用：

```powershell
.\scripts\uninstall_windows.ps1 -RemoveData
```

安全冒烟（不隐藏 Windows 桌面）：

```powershell
.\scripts\run_windows.ps1 --smoke
```

紧急恢复：

```powershell
.\scripts\restore_windows.ps1
```

## 莉莉丝对话模型

主对话使用 `gpt-5.6-terra`（medium），复用当前电脑上 Codex 的 ChatGPT 订阅登录，不需要 OpenAI API Key。每次生成都使用临时会话；固定身份、分区目录和按需召回片段从本地 SQLite 注入，对话数据不写入 Codex 历史。空闲五分钟后关闭连接。

电脑中已有的 `Qwen2.5-0.5B-Instruct` safetensors 检查点继续通过独立 CPU 进程保留；在提交一轮对话前检测到断网、订阅退出或 GPT 不可用时由它离线接替，不下载或扫描其他模型。已经提交给 GPT 的一轮若在生成中失败，会明确提示重试，不会在同一任务锁内悄悄跨模型续写。主动陪伴不会持续观察桌面；只有用户明确开启智能观察、隐私策略允许且窗口满足稳定/停顿条件时，才向支持图像的 Luna 或 Terra 发送一次当前活动窗口。模型动作只能访问注册过的组件；v0.3 不向模型或对话输入公开任意 Shell，组件结果由程序直接呈现，不交给模型改写。

检查现有离线备用 0.5B 是否可用：

```powershell
.\scripts\install_model.ps1
```

这个脚本只做本机检查，不安装也不下载模型。
