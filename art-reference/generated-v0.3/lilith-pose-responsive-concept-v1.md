# Lilith responsive pose concepts

Status: concept reference only; deliberately excluded from the runtime theme.

Generated references:

- `lilith-pose-responsive-concept-v1-rgb.png`
- `lilith-pose-responsive-concept-v2-rgb.png`

The two sheets explore four contact-aware silhouettes for desktop use:

1. narrow title-bar sit;
2. wide-window prone perch;
3. vertical screen-edge peek;
4. compact corner retreat with clasped hands.

Character lock used for generation: front-facing two-head chibi Lilith, very
slender and pale, short white bob, gently closed eyes, quiet expression,
white cotton dress, non-bloody cold-white bioceramic cracks, restrained red
collar connector, clean contemporary Japanese game-UI rendering.

The image generator baked a checkerboard into both RGB outputs even after an
explicit alpha cleanup edit. They must not be referenced from `theme.json` or
packaged as production sprites. Runtime pose variants currently reuse the
verified transparent masters and preserve these concepts only as art direction
for a later true-RGBA redraw.
